## 🚀 WHAT IS THIS PLACE

This is not a portfolio. This is not a "clean, professional" repo with perfect commit messages.

This is a **war journal**. Every solved problem, every stupid off-by-one bug, every 2 AM "OH WAIT IT'S A HASHMAP" moment — it all gets committed here. No filters, no shame, just raw grind toward becoming someone who doesn't panic when they see the word "Trie."

> 🎯 **Goal:** Get so comfortable with algorithms that Big-O starts showing up in my dreams.

## 🔥 RULES OF THE GRIND

1. **Commit every solve.** Ugly code counts. Working code counts more.

3. **Write `notes.md` for every problem** — future me is an idiot and needs reminders.
4. **If it took 3+ attempts — mark it for review in a week.**
5. **Celebrate the small wins.** Every accepted submission deserves a mental fist pump.
